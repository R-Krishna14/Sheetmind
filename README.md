**SheetMind Pro** is a browser-only Excel intelligence web app that transforms any spreadsheet into a powerful interactive experience.

## ✨ Features
- Upload Excel (.xlsx, .xls) and CSV files
- Multi-sheet support
- Auto column profiling (type, fill rate, stats)
- Global search and smart filters
- Column hide/show
- Sorting and pagination
- Built-in charts (Bar, Line, Pie)
- AI-powered natural language queries (Claude / GPT)
- Export filtered data to CSV
- 100% client-side — no server upload

## 🔐 Privacy
All data stays in your browser.  
API keys are stored locally and never sent anywhere except the AI provider.
